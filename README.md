# Habit Tracker CLI

A command-line app that helps you build routines by tracking daily and weekly habits and showing your streaks. Data is saved in a JSON file.

## Install
pipenv install

## Run
pipenv run python main.py --help

## Commands
- add-habit NAME (add --weekly for a weekly habit)
- list-habits
- check-in NAME
- streak NAME

## Run tests
pipenv run python -m pytest
